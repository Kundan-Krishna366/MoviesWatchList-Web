# Movie App

A React-based movie application using the TMDB API to browse and search movies.  
Users can add favourites and watch movies via VidSrc.

## Live Demo
https://moviecore.netlify.app/

## Setup
Create a `.env` file with your TMDB API key:

```env
VITE_TMDB_API_KEY=your_tmdb_api_key
```

## Note
This application is responsive across desktop, laptop, tablet, and mobile browsers.

## Features
- Popular & search movies
- Add/remove favourites
- Watch movies (VidSrc embed)
- Fast & responsive UI
